# 项目检查与 A5 可靠性优化 · 2026-09-07

基础版本：`test` / `9332b7b`。本轮不合并 main、不发布网站、不执行云 SQL。

## 已定位并处理

| 问题 | 修正 |
|---|---|
| 每次正式操作后重读个人数据，覆盖未保存草稿 | 每题只初始化个人工作区；保存队列确认快照，不替换新输入 |
| 草稿保存无题次参数，旧请求可能写入下一题 | V1.1 RPC 校验局次/题次；共享房间读锁固定题次，各玩家草稿独立版本控制 |
| 同一玩家多个窗口、延迟请求覆盖草稿 | 按草稿版本乐观校验；冲突保留当前文字，显式选择；断网草稿暂存当前标签页 |
| 重复请求在房间锁前查询幂等记录 | 新 RPC 锁后查询，校验操作者/类型/内容；重试返回最新状态 |
| 空判定仍能进入旧 SQL 分支 | 新 RPC 拒绝缺失/非法判定和过长补充说明 |
| 旧反馈可能写入下一题，重复反馈也增加房间版本 | 新 RPC 校验题次并提前返回重复结果；恢复页面可识别已提交反馈 |
| 结束本局残留待判定行动且不公开汤底 | 清理待判定内容、公开汤底并只结算一次；增加行内确认 |
| 汤主资料只展示 4 秒且套用浮动词牌样式 | 完整单元格换行，最长阅读 5 分钟，闲置 60 秒隐藏；保留 Esc/失焦/切页遮挡 |
| 开始前“帮助”无法切页、文字输入被截断 | 帮助独立于房间状态；可返回原工作表，多行草稿/反馈，状态栏不挡正文 |
| 默认 Vinext 打包跳过四个游戏路由且 Windows 退出断言失败；文档过时 | 默认 build 改为已验证的 Next 静态构建，build:pages 保持兼容；原构建保留为 build:sites，CloudBase 产物统一 out；同步通知位置与评分说明 |

## 验证方式

- 原有 A2/A3/A4 回归保持运行，不修改它们的界面或玩法状态机。
- 增加本地 PGlite，执行原 V10 与新 V10.1 SQL；模拟匿名角色、成员身份、3/5/8/10 人完整轮转。
- 验证非成员拒绝、侦探不见汤底、表直接读取拒绝、草稿隔离、题次保护、重复操作、20+5 问、提示上限和反馈。
- 用可控制的异步响应验证草稿保存串行、旧响应不能覆盖新输入、离开旧题后回调无效、冲突选择和断网重试。
- 不将 SQL 文本包含某关键词视为功能验收。只读核验仅检查已安装对象；真实云环境的权限、网络、多连接锁行为还需人工实测。
- 本轮 120 项自动测试、Lint 和 Next.js 静态构建通过。Vinext 原构建编译后跳过四个游戏路由，在 Windows 退出时触发 `UV_HANDLE_CLOSING` 断言；该可选链路未修复，已移出默认 CloudBase 打包路径。
