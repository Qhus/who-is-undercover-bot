# A2 V1.11 手动填词出题人模式

日期：2026-09-07。本次只调整 A2。

## 确认口径

- 系统随机：房主是普通玩家；两组词在创建前不向房主显示。
- 手动填词：房主是出题人，不计入“玩家数量”。
- 出题人不获得词牌，不描述、投票、爆灯、暂退、退出，不计入阵营人数和胜负。
- 出题人仍是房主，可生成个人信息、推进阶段、暂停自动进入和再开一局。
- 等待房间同时展示出题人和实际玩家进度；房主、加入者和规则页看到同一口径。

## 联机实现

- 房主仍作为 `game_members` 成员保留鉴权和推进权限。
- 公开房间状态中将出题人标记为 `hostOnly: true`、`alive: false`，不生成词牌分配。
- `join_game_v34` 和 `apply_game_action_v34` 在容量和等待房间配置中只统计非 `hostOnly` 成员；其他成熟流程继续委托 V3.1 RPC。
- 旧房间没有 `hostOnly` 字段时默认所有成员均是玩家，保持兼容。

## 验收

1. 系统随机建房：3 人局的房主占 1 个玩家名额，建房前不显示词组。
2. 手动填词建房：3 人局显示 0/3 名玩家和 1 名出题人，允许 3 名其他人加入。
3. 发牌后只有 3 份词牌；出题人页面只显示等待和推进操作。
4. 描述、投票、爆灯和胜负都只统计 3 名玩家。
5. 现有 A2 随机模式及 A3/A4/A5 回归通过。
