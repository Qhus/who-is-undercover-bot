# V1.10.2 工作簿界面统一

日期：2026-09-07。用户已确认开发；基于本地 `test` / `6405e75`。只做前端呈现，不调整玩法、计时、评分、RPC 或 SQL。开发完成后用户追加授权推送 GitHub `test`，不合并稳定分支、不执行站点部署。

## 已确认方向

- 目录及 A2–A5 统一绿色标题栏、单元格、底部工作表；外层使用“协作工作簿 · 编号”，说明表内保留真实名称与规则。
- 电脑全屏优先，兼顾 1366×768、1920×1080、约 1024px 宽桌面；基本手机操作入口保留，不通过缩小文字硬塞内容。
- 短指引告诉玩家下一步做什么。详细规则和公开长文本点击后进入底部批注，不悬浮遮住输入；可收起、展开、关闭。
- 普通反馈进入状态栏；错误明确标注“需要处理”，不自动弹窗。草稿保存与正式提交继续分开提示。
- 顶部入口与底部 Sheet 可操作；缺少房间时禁用相关工作表。帮助记录来源并返回原工作表。
- A2 的创建／加入不再用 A4 指代角色入口；保留明确的提交、确认和词牌行为，不为隐蔽而模糊后果。

## 实施

1. 共用 WorkbookFeedback / WorkbookText / WorkbookColumns 及作用域化批注；批注只接受显式传入的公开文本。
2. 逐页统一标题、修复顶部导航、接入帮助返回与状态栏；删除装饰性但不可操作的假工具条和新增工作表按钮。
3. 按页面设置列宽，正文换行；A4 两段陈词改多行输入，仍各限 80 字；窄桌面通知栏改为上下布局。
4. A2 私密词不再进入公式栏；复看词牌保持按钮原位。轮次记录的当前轮描述遵循已有公开条件。
5. 补充真实组件渲染、导航、批注及隐私边界回归测试；运行原有游戏测试、Lint、类型检查、静态构建。

## 信息边界

- 禁止从 DOM、输入框、私密资料对象自动采集批注。
- A2 私密词、A3 目标答案／未公开提示、A5 汤主资料／独立草稿不作为批注来源。
- A5 公开汤面、待判定内容、已公开提示和问答记录可查看完整批注；汤主工作表永不接入通用批注。
- 工作表、房间、局次或阶段改变后清空旧批注。保留已有 Esc、失焦、闲置遮挡机制。
- 没有游戏数据结构或云端权限变更；无需用户执行 SQL。
