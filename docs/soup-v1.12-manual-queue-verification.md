# A5 汤底侦探 V1.12.0 验证记录

## 自动验证

- 本地 PostgreSQL 兼容运行：V10、V10.1、V1.12.0 迁移连续执行两次成功。
- 数据库流程覆盖：建房、加入、随机汤主、私密手动出题、双草稿、两名侦探各自同时入队、重复排队拒绝、队首判定、个人 10 秒冷却、公开图文证据、成功还原、揭晓和下一碗换汤主。
- 只读核验覆盖：私密表与 RLS、五个 V1.2 RPC、匿名执行权限、每人最多一条、冷却逻辑、汤主轮换和图片链接字段。
- 前端回归覆盖 A2、A3、A4 既有流程及 A5 新文案、隐私与 RPC 绑定。

## 云端执行顺序

1. 已确认环境存在 V10 与 V10.1。
2. 执行 `cloudbase/concurrency-v12-soup-manual-queue.sql`。
3. 执行 `cloudbase/verify-v12-soup-manual-queue.sql`，确认每行 `ok=true`。
4. 部署前端并新建 A5 房间；不要继续使用旧 A5 房间判断升级是否成功。

## 多浏览器验收

使用至少三个独立浏览器身份：

1. 创建房间并让三人加入，开始后确认汤主随机产生。
2. 汤主填写手动题，侦探只能看到汤面，看不到汤底或判定资料。
3. 两名侦探几乎同时各提交一条，确认都进入队列且顺序稳定。
4. 同一侦探再次提交应被拒绝；汤主只能回答队首，回答后下一条自动成为队首。
5. 被回答的侦探若仍在个人 10 秒冷却内不能再次提交，结束后恢复。
6. 发布带图片链接的汤面或证据，确认点击前不加载，点击后才显示。
7. 成功还原后确认所有输入停止、汤底公开；下一碗保留成员并换用尚未担任过汤主的玩家。

本地自动化不能替代 CloudBase 的真实多连接并发、网络中断和移动端窗口验收。
