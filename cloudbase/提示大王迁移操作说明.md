# 提示大王 V1 CloudBase 操作说明

## 需要人工执行

1. 打开 CloudBase PostgreSQL SQL 编辑器，使用当前可创建新函数的管理员角色。
2. 完整执行 `concurrency-v8-clue-king.sql`。
3. 执行 `verify-v8-clue-king.sql`。
4. 确认核验结果中每一行 `ok` 都为 `true`。
5. 再重构或部署包含 `/clue/` 的前端版本。

## 脚本影响范围

- 新增 100 个启用词语。
- 新增 A3 专用私密表和 V1 RPC。
- 不覆盖谁是卧底 RPC。
- 不覆盖离谱法堂 V6/V7 RPC。
- 不删除旧表、旧函数或现有房间。

## 部署后验收

- 至少使用三个独立浏览器或无痕窗口。
- 覆盖普通提示、随机限制、重复提示、猜错、猜中评分、评分超时、双榜单和再来一局。
- 旧 A2、A4 各创建一次房间，确认没有回归。

如果迁移或核验报错，请保留完整错误信息和失败语句，不要重复执行其他历史迁移。
